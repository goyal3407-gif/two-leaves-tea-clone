# Two Leaves Tea - Website Clone (Practice Project)

A front-end practice clone inspired by the layout of twoleavestea.com, built to learn HTML, CSS and JavaScript. This is a learning project only - it is NOT the real store and is not affiliated with Two Leaves and a Bud. All code is written from scratch; product photos are free Unsplash images.

## What is inside

- `index.html` - page structure (header, hero, best sellers, reviews, our origins, lattes, wholesale, journal, footer, cart sidebar)
- `style.css` - all styling, flexbox layout, mobile responsive with media query
- `script.js` - product data, category filter, working cart (add/remove/total), reviews slider, mobile menu, newsletter check

## Features

- Filter teas by type - Black, Green, Herbal, Latte Mix
- Add to cart with a slide-in cart box and live total
- Reviews slider with next/previous buttons
- "Explore by vibe" buttons that filter the shop
- Newsletter email validation in plain JS

## How to run

Just open `index.html` in a browser. No server or build step needed.
